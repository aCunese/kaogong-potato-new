# 考公工作台 · 土豆陪伴版 Android UI

本版按用户 2026-10-26 提供的奶油白/鼠尾草绿参考与黄色土豆形象设计。此前蓝色 prompt 保留为历史交付，本版视觉以这里的设计图为准。

## 交付

- 8 张独立主板块：今日计划、事项库、题本进度、网课进度、错题复盘、总体分析、每月分析、我的与设置。
- 20 张独立操作与状态：专注计时、添加计划、三类完成登记、登记成功、题本/网课编辑、自定义事项、照片导入/详情、考试日期、未登录、登录、注册、同步、备份、资料编辑、今日空态、删除确认。
- 八种土豆动作素材；保留为透明 PNG 图集，页面通过 CSS 使用，无需请求外部图片服务。
- 主设计为 412×915 逻辑尺寸，独立 PNG 以 2 倍输出为 824×1830。
- 360×800 小屏检查图以 720×1600 输出，覆盖今日、长表单、月度统计与登录。
- index.html 可在浏览器打开，主界面是可浏览的全部页面画廊。点击页面可查看原尺寸与页面间演示跳转。

## 风格

奶油白 #F4F3EB，纸白 #FFFDF8，鼠尾草绿 #61794F，深墨绿 #343C2F，土豆金 #E6B957。土豆出现在欢迎、学习、听课、复盘、分析、数据管理与完成反馈中。资料数据区域保留清楚的数字、进度与操作。

底部五入口为今日、学习、错题、分析、我的。原八模块保持独立页面，学习内部切换题本/网课/事项库，分析内部切换总体/月度。

## 角色生成

角色素材使用内置 imagegen 根据用户给出的末张土豆参考图衍生生成，保存为 assets/potato-poses.png。绘制八个等比例、透明背景、4×2 排列动作：挥手、读书、戴耳机、放大镜查错、展示图表、使用电脑、庆祝、写笔记。保持黄色不规则土豆轮廓、棕色手绘描边、黑白圆眼、橙色脸颊与黑色细手脚。

使用的完整生成提示词见 asset-prompt.txt。UI 的排版、中文、数值与图表以 HTML/CSS/SVG 精确组织，经浏览器导出设计图，避免生成式位图中的文字错误。

## 演示与实现边界

日期与数据为虚构演示：2026-10-25，今日 2/4 完成、65 分钟，月度1260分钟/420题/84错/80%。考试日期只是设计示例。

预览不读取真实工作台，不登录真实账号，不上传照片，不连接产品 API。按钮展示页面间跳转，不代表原产品的后端与同步修复已经完成。原产品 index.html、server.js 和 Android 源码保持原样。

错题图片是自行绘制的演示题纸；用户提供的截图仅用于参考布局与配色。没有提取截图中的个人记录作为真实数据。

真实项目仍按原先梳理的口径：学习记录来自完成登记，直接改累计值不回填记录；照片条数与错题题数独立；课程使用外链；不增加 AI、OCR、播放器或会员支付。

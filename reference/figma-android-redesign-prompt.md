# 考公工作台 · Android UI 重设计最终 Prompt

请作为资深 Android 产品设计师、交互设计师和设计系统负责人，为中文 App「考公工作台」完成一套可供开发实现的高保真 UI、组件系统与可点击原型。目标是成熟商业付费效率工具的完成度：专业、安静、精确、适合每天长时间使用。

这是一套已有产品的完整移动重设计。请以以下真实功能、数据口径与实现边界为依据。优先交付可操作的产品页面，界面中的文案使用自然简洁的中文。请直接采用以下确定的视觉方向，不再生成多套风格供选择。

## 1. 产品定位与真实业务

产品名称保留「考公工作台」。用户是同时准备国考、省考、事业单位考试的人，核心需求是每天安排学习、记录学习投入、跟踪题本与网课进度、保存错题照片，并回看数据。

核心流程：题本或网课自动生成对应事项；也可新建自定义事项 → 从事项库加入今天 → 开始或暂停正向计时 → 完成时登记题量、错题、课时与实际分钟 → 更新来源进度并生成学习记录 → 总体与月度分析汇总记录。错题照片及复盘原因独立管理。

当前功能涵盖八科，顺序固定为：资料分析、判断推理、言语理解、数量关系、政治理论、常识判断、申论、面试。申论和面试同样可用于通用题本、网课和自定义事项，没有专属评分或专属训练流程；只有时长而没有题量时不显示正确率。

当前实际技术形态是 HTML/CSS/JavaScript 应用加 Android WebView 壳，自建服务器负责账号与整份数据同步。本次设计可以重组页面与组件，保持现有业务数据和接口语义。下文的全屏计时页、底部导航、表单校验、明确的覆盖确认与状态反馈属于本次移动体验完善，开发交付注释中标注为待实现的 UI/交互要求。

不要添加在线答题、题目正文与答案库、自动批改、AI 解析、OCR、课程播放器、课程商城、会员支付、排名社区、打卡积分、考试报名、消息推送、智能复习算法。商业质感体现在设计质量，不需要充值页或会员广告。不要画当前未接通的 Supabase 管理、独立照片云盘、历史云快照恢复入口。

- 内容表面：#FFFFFF。
- 次级表面：#EEF1F6。
- 主色和主要按钮：#2447A6。
- 主色浅底：#EEF2FC。
- 深色重点区域：#172A4D，仅少量用于今日概览或计时数字区域。
- 一级文字：#16233B。

中文使用 Noto Sans SC 或相近的 Android 中文无衬线字体，数字和英文使用 Roboto，启用等宽数字。页面标题 24/32、区块标题 18/26、项目标题 16/24、正文和输入内容 16/24、次级信息 14/22、短辅助信息 12/18。关键统计数字 28–32，计时数字 48–56。字重以 400、500、600 为主。不要为容纳内容缩小中文字号。

统一线性图标，视觉尺寸 20–24，线宽约 1.75–2。卡片圆角 16、按钮和输入框圆角 12、底部抽屉顶角 24。阴影仅少量用于浮层、底部固定操作区和正在计时的浮条。不要大面积渐变、玻璃模糊、厚重阴影、金色装饰、大号欢迎语和重复标题。移除常规业务界面中的装饰猫图；自定义头像可以保留用户选图。

## 3. Android 画板与适配规范

- 主设计画板：412 × 915，单位采用逻辑尺寸，Figma 中以 1px 对应约 1dp 的布局标注理解。不要把设备截图的物理像素直接作为布局尺寸。
- 另外提供 360 × 800 和 393 × 873 的适配检查画面，至少检查今日、长表单、分析三类页面。使用同一套组件响应式变化，避免整页等比缩放。
- 以安卓竖屏、手势导航为主，同时标注三键导航、挖孔屏和显示缩放时的避让要求。
- 页面左右边距 20；360 宽可缩到 16。间距体系 4/8/12/16/20/24/32。
- 顶部应用栏 56；底部导航内容区 80，系统手势区另外预留，不能重复叠加安全区。
- 设计样稿可暂用顶部系统区 24、底部手势区 24；这只是展示占位，实际实现以 WindowInsets、切口和键盘高度为准，不把系统区硬编码为所有设备统一高度。
- 图标和文字按钮可见尺寸可以较小，但触控热区至少 48 × 48，主按钮高 52。
- 背景可延伸到系统栏，内容与可操作控件避开状态栏、切口、导航栏和系统手势区。
- 顶栏、底部导航、滚动内容、底部保存区分别定义约束；列表底部留足空间，最后一项和按钮不能被导航或计时浮条盖住。
- 键盘出现时，表单滚动、焦点字段可见，保存按钮与键盘协调；没有必要时隐藏底部导航。提供一张长表单键盘展开示意。
- Android 返回操作优先关闭键盘、抽屉、图片详情和二级页，再返回顶级页面；这些返回层级要在原型和交付注释中明确。
- 不加入 iOS 刘海、Dynamic Island、iOS 风格底栏或滑动返回视觉。
- 普通文字对比度目标至少 4.5:1。字号放大到 130% 时检查标题、任务名、数值和按钮；不能只依靠颜色区分状态。

## 4. 导航与信息架构

采用五项固定底部导航，标签与顺序固定为：今日、学习、错题、分析、我的。

1. 今日：原「今日计划」，包含三个考试倒计时、今日概览、今日任务、计时与完成登记。
2. 学习：顶部切换「题本 / 网课 / 事项库」，保留三个原模块，名称与来源关系明确。
3. 错题：原「错题复盘」，按题本分组的照片记录。
4. 分析：顶部切换「总体 / 月度」，保留两个不同的分析口径。
5. 我的：个人头像和显示名称、账号状态、同步、文件备份、数据自检和重置。

顶级页面只有一处主标题。二级详情、编辑和专注计时页使用返回顶栏，进入长表单和图片详情时不显示底部导航。保留从学习资料到事项库、从事项加入今天、从今日任务到完成登记的连贯关系。

## 5. 今日：让用户打开就能开始学习

首页从上到下组织：

1. 顶部「今日」与日期，右侧一个小型同步状态入口；不重复显示两遍「今日日程」。
2. 紧凑的今日概览：已完成任务数/总数、已登记学习时长。使用对齐的数字，避免四五张小卡拼贴。
3. 一条紧凑的考试倒计时区域，展示事业编、国考、省考三个入口。412 宽可三列，360 宽也保持短文案；字体放大时允许换行或改为紧凑列表。每项名称、剩余天数、日期明确，未设置显示「设置日期」。不要把三个考试做成占满首屏的三张大卡。
4. 「今日任务」列表及明确的「添加任务」入口。915 高的默认首屏至少露出一项完整可操作任务。

任务需要区分刷题、网课、自定义三类，展示名称、科目、计划分钟、已累计实际分钟与任务状态。任务名称允许两行。主要操作随状态变化：开始计时 / 暂停 / 继续计时；「完成登记」为明确的次操作；删除进入更多菜单。完成态保留登记结果摘要，不能再次计时或重复登记。删除已完成任务不会撤销已有学习记录，此语义需说明。

计时采用正向累计时间，展示如 25:18，区分本段计时与此前累计；不能改成倒计时番茄钟。设计一张可从任务进入的全屏专注页，含任务、科目、计划时长、累计时间、暂停/继续和完成登记。离开专注页后在应用内用紧凑计时浮条继续访问；这是应用内浮条，不是系统悬浮窗或通知服务。仅一个任务计时时浮条直达该任务；多个任务计时时显示「X 项正在计时」并展开运行列表，各任务独立暂停/继续，不合并它们的计时值，也不自动暂停其他项。

必须有：无任务、待开始、单项正在计时、多项同时计时、暂停、已完成、来源题本/网课已不存在的提示状态。空态文案示例：「今天还没有任务，从事项库选择一项开始。」

「添加任务」使用底部抽屉：事项选择列表，标明题本/网课/自定义来源与科目；选定后输入计划分钟；主按钮「加入今天」。日程只安排到今天，不出现未来日历和重复计划。

倒计时设置使用日期选择流程，三个考试名称固定。样例中倒计时日期必须与样例今天一致计算。

## 6. 三类完成登记：保留不同数据结构

完成按钮打开适合手机的登记 Sheet；内容较长时扩展为全屏。

- 题本任务：本次做题数、本次错题数、实际学习分钟。显示所关联题本，按钮「保存并完成」。
- 网课任务：本次完成课时、实际学习分钟。显示所关联课程，按钮「保存并完成」。
- 自定义任务：事项名称与科目只读，实际学习分钟可填写，按钮「保存并完成」。

有计时数据时预填实际分钟，没有计时数据时允许手动登记；不要称为自动监测。界面显示保存中、成功、失败及重试；防止重复点击。数值错误贴近字段说明：不能为负，错题数不能超过本次做题数。完成后返回今日，任务进入完成态，并更新相关进度和分析。

## 7. 学习：题本、网课、事项库

### 题本

题本列表展示名称、科目、题量进度、已做/总题数、正确率、平均分钟/题。长名称完整可读，卡片右上为更多菜单。编辑和删除可从更多进入；「加入今天」可复用该题本自动生成的事项。不要出现「开始答题」。

题本新增/编辑使用全屏表单，字段必须完整：题本名称、所属科目、总题数、页数、已做题数、错题数、累计分钟。字段按基本信息与累计进度分组，保存操作固定在可达位置。

重要说明：「修改累计数据不会补写学习记录，分析以任务完成登记为准。」放在编辑表单的合适位置，避免用户误解数据联动。

### 网课

课程列表展示名称、科目、已完成/总课时、进度、累计分钟；有效外链显示「打开课程」及外链图标。链接为空时展示「未添加课程链接」和编辑入口，不画播放器。

新增/编辑完整字段：课程名称、所属科目、总课时、已完成课时、累计分钟、课程链接。完成课时以人工登记为准。保留删除确认及「同时移除对应事项，历史学习记录保留」的说明。

### 事项库

展示题本事项、网课事项和自定义事项。每本题本和每门网课自动对应一个事项，不能画成可以独立复制多份的来源记录。每项包含来源类型、名称、科目、默认分钟及「加入今天」。题本和网课内容编辑回到来源资料；自定义事项可新增、改默认时长和删除，不添加尚不存在的名称编辑业务。

自定义事项表单：名称、八科之一、默认分钟。题本默认 30 分钟、网课默认 60 分钟，界面允许调整；具体持久化问题由实现修正，设计不宣称已有模板或自动计划。

这三类列表保留默认态与空态。此次不添加搜索、排序、收藏、标签体系和全局筛选。

## 8. 错题：照片与复盘原因

按所属题本分组呈现错题照片，日期和复盘原因摘要清晰。小图作为浏览入口，题目细节在详情中阅读；不要在小缩略图里模拟完整可读试卷。

「导入照片」流程：先选所属题本 → 调用 Android 系统图片选择器多选已有照片 → 展示所选缩略图 → 填写复盘原因 → 保存。一次选择的照片共用本次复盘原因，一张照片生成一条记录。没有题本时引导先添加题本。不要画拍照按钮、相机扫描、OCR、自动分类、裁剪和手写批注。

处理状态展示「正在处理 2/4 张照片」，支持部分保存失败反馈，清楚说明已保存几张、剩余几张失败。详情保留照片大图、所属题本、日期、复盘原因，提供返回与删除；不添加原实现没有的备注编辑、掌握度和复习日历。

图片失败时用中性图片占位与文字，不能用猫图代替题目内容。删除用确认层。

错题照片条数与手工登记的错题题数是不同指标。当前照片以内嵌压缩图随工作台数据保存和同步，不把它描述为具备独立上传进度的云相册。

## 9. 分析：正确展示学习记录

### 总体

范围严格为最近 30 天、最近 90 天、全部记录。展示：

- 学习时间分布：环形图中心总时长，配八科完整图例，逐项显示分钟和占比。无学习时间时显示空态。
- 各科每日正确率：由当天该科登记的题量和错题汇总计算。纵轴固定 0–100%，时间横轴稀疏，图表文字按手机实际尺寸设计，不能缩小一整张桌面 SVG。

八科数据均可查看。默认突出一条科目线，其他线降低强调；通过图例点选观察属于本次图表交互完善，标注给开发。提供清晰的日期、题量、错题、正确率浮层示意，不只依赖 hover。

### 月度

提供明确的年份与月份选择。指标为总学习分钟、做题量、错题题数、整体正确率，可用两列数字区域。展示八科正确率条形列表及各科登记用时。

每行优先采用「科目名 + 右侧数值」并在下一行显示横条，保证小屏空间；不要挤进桌面表格。没有题量的科目显示「暂无题量记录」，不能用 0% 表示答题水平；申论和面试只有时长时仍显示时长。

不要增加学习目标达成率、考试分数、预测排名、同比环比、连续打卡天数等当前未提供的指标。所有分析只来自完成登记生成的记录，暂停计时或直接改累计值不会自动补写记录。

## 10. 我的、账号、同步与数据管理

「我的」顶部只放头像、显示名称、账号状态；显示名称与登录用户名是不同字段。功能按简洁设置列表组织。

- 个人资料：修改显示名称、从系统相册选头像；不增加手机号、邮箱、身份认证和会员等级。
- 未登录：允许继续本机使用，提供登录与注册。
- 登录/注册：用户名、密码，支持密码可见切换。注册使用当前服务约束：用户名至少 2 个字符、密码至少 4 个字符；不要添加短信、邮箱验证码、第三方登录、忘记密码或修改密码入口。账号页只保留现有账号信息、同步操作和退出。
- 同步：已保存在本机、正在同步、已同步、连接失败、登录已过期等状态。联网与登录状态分别表达。手动「上传本机数据」「从云端读取」操作说明影响范围，覆盖本机或云端前提供明确确认。
- JSON 备份：导出、选择 JSON 导入，提供处理中、成功、格式错误、失败反馈；导入会覆盖当前工作台，确认中清楚写出这一点。
- 数据自检：显示题本/网课与事项映射检查结果。不要宣称检测或修复了所有数据问题。
- 重置工作台：放在低频危险操作区域，确认文案说明当前实现可能影响已登录账号的同步数据；不写「只清本机、云端不受影响」。
- Android 安装包：保留为网页分发场景的次级入口，不在已安装 App 的首页做下载宣传；原生页面的关于信息不额外虚构新能力。

同步成功只在真实请求成功后表达。断网保存显示「已保存在本机，待连接后同步」。不要使用「永不丢失」「永久保存」「绝对安全」「多设备实时无缝同步」等保证。

整份状态的同步存在覆盖语义，本次不画版本合并、冲突解决器、自动账号数据迁移或后台可靠同步已经完成。Android 的文件导出、离线来源切换、返回与安全区仍需开发适配，不能用设计原型代表它们已实现。

# 番茄钟类别预选与自定义倒数日实施计划

依据：用户 2026-10-28 测试反馈（已逐项确认）。

## 需求定稿

### 1. 番茄钟：先选类别，结束自动登记
- 开始前必须选择学习类别（八科＋其他，3×3），开始后锁定（含暂停）。
- 计时结束自动登记为 `type:'custom'` 学习记录：科目=所选类别、分钟=整分钟；今日日程显示已完成条目「番茄钟 · 申论」；不更新题本做题量、错题数、网课节数。
- 统计口径（方案 A，两处都记）：
  - 用时分布 → 专注与休息：专注时间包含番茄钟专注时长（休息单列且不计学习用时）；
  - 用时分布 → 自定义学习、学习用时明细 → 自定义学习/科目/总学习用时：同一份时间只累计一次。
- 旧版本遗留的待登记会话（无类别）：保留原「关联学习事项」补登记流程，不动历史数据。
- 番茄钟四个模块（正计时/倒计时/专注时间/休息）的用时都进入上述统计。

### 2. 倒数日：自定义名称与日期（像倒数日 App）
- 保留「国考/省考/事业编」三项作为默认，可改名、改日期、删除，并可新增。
- 最多 6 个；首页一行横向滑动；过去日期显示「已结束」；未设置日期显示「-- / 设置日期」。
- 点卡片打开编辑（名称/日期/删除二次确认），并提供「＋ 添加倒数日」入口。
- 备份/同步保留用户自定义与删除结果，不再强制补齐三个固定项；旧 ID 迁移逻辑保留；服务端原有 100 个上限与 40 字名称上限继续生效。

## 实现要点
- `TimerSession.subject?: StudySubject`（Schema 5 可选字段，不改版本、无需迁移）；同步/备份通过 `sessionValidation` 校验类别合法性。
- `applyFinishAndAutoRegister`：一次原子操作完成「结束+登记」，重复调用不产生第二条记录；跨天分段逻辑复用原实现。
- 倒数日：`applyAddCountdown / applyUpdateCountdown(name?) / applyDeleteCountdown`；自检规则从“必须 3 个”改为“字段合法”。
- UI：番茄钟弹窗重写（类别选择、锁定展示、自动登记、旧待登记表单）；首页倒数日横向滑动＋已结束态；倒数日弹窗支持新建/编辑/删除。

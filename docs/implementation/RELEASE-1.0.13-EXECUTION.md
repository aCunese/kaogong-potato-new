## 1. 核心改进点

1. **今日聚焦（Today Focus）**：
   - 主列表仅渲染「今天」的待办任务，彻底消除因历史待办无限平铺造成的瀑布流冗长问题。
   - 包含今日专属进度计数（如 `1/2`）与空态引导。
2. **逾期智能顺延提示（Overdue Rollover Alert）**：
   - 自动检测今天之前（如昨天）遗留的未打勾任务。
   - 顶部提供温和提醒条：“昨日有 1 项未完成待办：言语 [一键移到今天] [忽略]”。
   - 点击一键移到今天，自动将任务归属日期平滑更新为今日，并合并到今日待办中。
3. **仿微信「按日期查找」打卡月历（WeChat-style Calendar View）**：
   - 底部提供可折叠的【打卡月历与历史待办】面板，不占主屏空间。
   - 完美复刻微信克制高级的日历交互：
     - 无待办日期：文字浅灰暗显，不可点击；
     - 有待办日期：文字高亮清晰黑色，鼠标悬浮有交互反馈，可点击；
     - 今天：绿色圆形徽标（白字绿底）；
     - 选中日期：外圈细圆环高亮。
   - 点击亮起的历史日期后，在月历正下方即时滑出该历史日期的待办列表，并支持补打勾、取消勾或删除。

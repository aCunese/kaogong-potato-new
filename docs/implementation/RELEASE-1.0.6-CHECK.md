## 本次找到并修复的遗漏

1. **独立专注目标读数（P2）**：此前“专注时间”没有使用目标分钟，表现与正计时相同。改为当前专注阶段目标剩余/超时读数；总专注累计保留，超时继续静默累计。新增目标、超时及跨休息阶段累计的渲染回归，先失败再通过；真实浏览器核验1分钟目标运行125秒显示`+01:05`。
2. **跨设备登记后的失效会话选择（P2）**：关闭待登记弹窗后，另一设备完成登记，本机仍绑定已登记会话，开始按钮报`TIMER_BUSY`。选择只允许仍需登记的pending会话；失效时自动清除并回退到活跃会话。真实Express/SQLite/IndexedDB通过远端提交+焦点同步复现失败；修复后不用离开今日页即可开始新计时。
3. **热备清单错误继承工作区Schema（发布阻断）**：发布元数据升5后，CLI将数据库热备清单也标记为5，而恢复器只接受备份容器格式3。现已明确区分：备份容器格式保持3，每个工作区仍可为Schema5；真实热备→独立临时目录恢复证明会话与Schema5完整保留。未修改数据库结构或执行生产迁移。
4. **发布识别遗漏**：原Web版本/build仍为上一版，无法正确识别新发布。按用户确认升级到Web1.0.6/20261028.01，同时修正版本接口与SW身份；已有APK元数据保持真实。

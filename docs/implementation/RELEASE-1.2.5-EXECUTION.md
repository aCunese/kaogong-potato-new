## 用户可见变化

错题照片使用适合分散文字的 OCR 版面识别，先识别中文，证据不足时回退中英文。图形、手写批注和留白较多的试题照片能够更可靠地判断阅读方向，自动按 90°、180°、270° 转正。新照片上传同步后逐图处理，列表、详情和全屏沿用同一方向结果；原附件不改。

判定继续要求总有效字符至少 12、整体加权置信度至少 45、领先其他方向至少 10，并额外要求至少 12 个置信度不低于 60 的有效字符，防止纯图形被误当文字而转错。不确定时保留原方向，详情提供「重新识别」；先前已保存为未能确认方向的图片可从此入口重新处理。

本次范围为阅读方向转正，未增加斜拍透视拉平或弯曲书页展开。

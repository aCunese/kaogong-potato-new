## 邮箱与一次性提醒

入口为「我的 → 学习提醒」。用户验证收件邮箱后可新增、编辑或取消指定日期时间的一次性提醒。验证码 6 位、有效 10 分钟、重发间隔 60 秒、最多尝试 5 次，存储 HMAC 并限流。新邮箱验证成功后替换绑定；解绑需确认，并取消待发任务。

每人最多 50 条活跃提醒，标题 1–100 字、正文最多 1000 字。界面显示设备 IANA 时区，保存 UTC 时间。已开始发送的任务不能编辑或取消；「已提交邮件服务器」表示 SMTP 已接受，不表示收件箱投递确认。

后台每 30 秒扫描 SQLite 任务，以事务、租约和 fence 领取。正常负载目标为到点 60 秒内提交；超过 60 秒标记延迟。故障后 24 小时内补发一次，超过则标记错过。明确暂时拒收最多尝试 3 次，重试间隔为 1、5 分钟；未知结果不自动重发，可经用户确认重新安排。服务退出时停止领取，等待在途任务，超时转为未知。

### 发信配置

服务器环境变量：`SMTP_HOST`、`SMTP_PORT`、`SMTP_USER`、`SMTP_PASS`、`SMTP_FROM`、`EMAIL_CODE_SECRET`。QQ SMTP 使用 `smtp.qq.com:465`；`SMTP_FROM` 填纯邮箱地址。587 端口要求 STARTTLS，465 使用 TLS，均验证证书。验证码密钥至少 16 字符，建议独立生成 32 字节随机值。配置缺失时其余学习功能照常运行。

本地私密配置位于 `.env.smtp.local`，由 Git 忽略，权限为 `0600`。不得提交或将其内容写入报告。开发环境可在项目目录运行：

```sh
npm run server:smtp
```

该命令启动当前工作区的后端并使用当前工作区 `data/`，不会读取原工作区或生产目录。前端可运行 `npm run dev`，默认代理本机 3000 端口。生产配置通过 `deploy/release.env.example` 中的空值模板和 Compose 环境变量注入；真实配置应独立保管。

## 学习数据共享

入口为「我的 → 学习伙伴」。主人生成 192 位随机分享码，10 分钟有效、仅能使用一次；朋友登录后兑换，获得持续只读权限，主人可随时撤销。分享码仅生成时展示，数据库保存 SHA-256，不复用注册邀请码或登录凭证。

共享包括昵称、云端同步时间、学习汇总、题本及网课累计进度、可按日期分页的学习记录。服务端使用显式白名单 DTO，排除邮箱、登录标识、头像、错题照片、笔记、课程链接、原始工作区和未来日程。每次请求核对查看者、主人状态、授权和 generation。接口 `no-store`；客户端状态独立，关闭或切换账号后中止请求，不进入个人工作区、IndexedDB、outbox 或备份。

## 接口与数据兼容

- `GET /api/account/email`，`POST /api/account/email/code`，`POST /api/account/email/verify`，`DELETE /api/account/email`。
- `GET/POST /api/reminders`，`PATCH /api/reminders/:id`，`POST /api/reminders/:id/cancel`；创建使用 `requestId`，修改与取消使用 `revision`。
- `POST /api/sharing/codes`，`DELETE /api/sharing/codes/:id`，`POST /api/sharing/redeem`。
- `GET /api/sharing/grants`，`DELETE /api/sharing/grants/:id`，`GET /api/sharing/grants/:id/overview`；概览支持 `from`、`to`、`page`、`pageSize`（最多 100）。

身份来自现有登录会话，写请求校验 CSRF；客户端带 `x-workspace-user` 防止切账号的旧请求落到新账号。

SQLite 通过 `account_features_schema=1` 标记增量迁移，邮箱和授权使用独立表，现有 AppState 与学习备份格式不变。完整服务端备份包含这些表；恢复支持旧版 9 张核心表备份，检查新版本表完整性，在暂存数据库中迁移。恢复换代会删除旧验证码，使旧分享码和授权失效，并暂停未发提醒，保留已验证邮箱。回滚代码时保留新增表，不做数据删除。

### 审阅后的边界修正

- SMTP 在 DATA 后断线且未收到最终确认时，Nodemailer 可能仍返回 CONN；该状态视为未知，阻止自动重复发送。已增加真实 loopback SMTP 断线测试。
- 已登记记录按保存日期参与共享统计，不以服务器 UTC 日期截断；未来日程由 DTO 白名单排除。
- 修正前先校验抵扣原登记后的剩余题量和错题数，避免接受随后无法撤销的矛盾累计。
- 提醒列表始终包含全部活跃任务，并额外保留最近 200 条结束记录。

最终验证：279 项单元测试、68 项服务端测试、24 项灾备测试，共 371 项通过；类型检查和生产构建通过。完整浏览器流程及 360/393/412 布局验收通过；无浏览器运行时错误。构建保留已有的主包体积提示。未进行真实收件箱投递验收。

## 2026-10-28 界面优化

“我的”页将个人资料和同步状态压缩为一张卡片，首屏直接呈现“学习提醒”“学习伙伴”。备份与应急恢复合并在“数据管理”，缓存清理和重置放入“更多数据操作”；“关于与更新”保留手动版本检查。功能处理、恢复点与危险操作确认保持原流程。

学习提醒已绑定时收起改绑输入，首次验证后直接填写提醒；“待发送”保留需要处理的异常任务，“历史记录”收纳已提交与已取消任务。界面以中文时区和具体日期时间确认保存。

学习伙伴默认“我查看的”，点击“添加学习伙伴”输入朋友的码；“谁可以看我”管理生成分享码和撤销查看者。详情保留只读、最后同步时间和日期筛选，减少重复统计展示。
